# Implementation Plan: `settings` (تنظیمات سیستم و انبار دارو)

**Date:** 2026-11-12  
**Stage:** Plan → Build → Test  
**Spec Reference:** `02-project/app/docs/superpowers/specs/2026-11-12-settings-design.md`  

---

## 1. Overview & File Map

Build the full-stack `/settings` feature for PharmaStock, with Persian headings, MongoDB persistence, RBAC checks, audit logging, and responsive clinical UI.

### Files to create / touch:

#### Backend (Go Echo + MongoDB):
- Create `02-project/app/backend/internal/settings/entity.go` — Settings domain models & defaults.
- Create `02-project/app/backend/internal/settings/dto.go` — Update request/response DTOs & validation.
- Create `02-project/app/backend/internal/settings/repository.go` — MongoDB persistence layer (`settings` collection).
- Create `02-project/app/backend/internal/settings/service.go` — Service layer with fallback defaults & audit recording.
- Create `02-project/app/backend/internal/settings/service_test.go` — Unit tests for service & validation.
- Create `02-project/app/backend/internal/settings/handler.go` — Echo handlers for `GET /api/v1/settings`, `PUT /api/v1/settings`, `POST /api/v1/settings/test-ttac`.
- Create `02-project/app/backend/internal/settings/handler_test.go` — Handler unit tests with RBAC & input validation.
- Modify `02-project/app/backend/cmd/api/bootstrap/app.go` — Wire `settings` service, handler, and routes into the server.

#### Frontend (Next.js + TypeScript):
- Create `02-project/app/src/lib/types/settings.ts` — TypeScript types matching the backend DTOs.
- Create `02-project/app/src/lib/settings/data-access.ts` — Client data access layer with local fallback mock and API client.
- Modify `02-project/app/src/lib/nav/app-nav.ts` — Add `settings` navigation item to the canonical sidebar items.
- Create `02-project/app/src/app/settings/page.tsx` — Server component with Persian metadata and layout wrapper.
- Create `02-project/app/src/app/settings/nav.ts` — Active navigation helper.
- Create `02-project/app/src/app/settings/settings-view.tsx` — Client component with 4 clinical tabs, form state, dirty tracking, saving, and TTAC test connection.
- Create `02-project/app/tests/unit/settings-view.test.tsx` — Frontend unit test verifying tabs, rendering Persian headings, and form submission.

## 2. Tasks

### Task 1: Backend Domain, Repository & Service Layer
- **Files:** `internal/settings/entity.go`, `internal/settings/dto.go`, `internal/settings/repository.go`, `internal/settings/service.go`, `internal/settings/service_test.go`
- **Actions:**
  1. Define `Settings`, `PharmacyIdentity`, `InventoryRules`, `TTACIntegration`, `SecurityConfig`.
  2. Implement `DefaultSettings()` with sane defaults matching existing constants (`30/90/180` days for expiry, `2/5/14` days for reorder).
  3. Implement Mongo repository with Upsert and Get.
  4. Implement `Service` that retrieves current settings (or defaults if empty) and updates settings with audit logging.
  5. Run unit tests: `go test ./internal/settings/...`.

### Task 2: Backend Handler, Routes & App Wiring
- **Files:** `internal/settings/handler.go`, `internal/settings/handler_test.go`, `cmd/api/bootstrap/app.go`
- **Actions:**
  1. Implement Echo handlers:
     - `GET /api/v1/settings`
     - `PUT /api/v1/settings` (checks auth token / user role)
     - `POST /api/v1/settings/test-ttac`
  2. Register routes under `/api/v1/settings` in `bootstrap/app.go`.
  3. Write and run handler unit tests: `go test -v ./internal/settings/...`.
  4. Verify entire backend compiles: `cd 02-project/app/backend && go build ./cmd/api`.

### Task 3: Frontend Data Types & Data Access Layer
- **Files:** `src/lib/types/settings.ts`, `src/lib/settings/data-access.ts`, `src/lib/nav/app-nav.ts`
- **Actions:**
  1. Define TypeScript types for Settings, tabs, and update payload.
  2. Implement `fetchSettings()` and `updateSettings()` with graceful offline fallback.
  3. Implement `testTtacConnection()` helper.
  4. Add `settings` item to `getAppNavItems` in `src/lib/nav/app-nav.ts`.

### Task 4: Frontend UI Components (`/settings`)
- **Files:** `src/app/settings/page.tsx`, `src/app/settings/nav.ts`, `src/app/settings/settings-view.tsx`
- **Actions:**
  1. Build `SettingsView` with `Tabs` / `TabList` matching the clinical design system:
     - هویت داروخانه و چاپ اسناد
     - قوانین انبار، FEFO و سفارش‌گذاری
     - ارتباط با سامانه تیتک (TTAC)
     - امنیت، نشست و ممیزی
  2. Implement form controls with labels, help texts, validation, and dirty state.
  3. Add "ذخیره تغییرات" button with loading state, dirty badge, and toast feedback.
  4. Add "آزمون اتصال به سامانه تیتک" with live latency report.
  5. Ensure Persian main headings: «تنظیمات سیستم و انبار دارو».

### Task 5: Testing, Verification & Integration
- **Files:** `tests/unit/settings-view.test.tsx`
- **Actions:**
  1. Create frontend Vitest tests checking tabs switching, initial values loading, and save action.
  2. Run frontend tests: `pnpm test` / `pnpm vitest run tests/unit/settings-view.test.tsx`.
  3. Run backend tests: `cd backend && go test ./...`.
  4. Run Next.js build / typecheck: `pnpm build` or `pnpm tsc --noEmit`.
